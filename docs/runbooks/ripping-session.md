# Ripping Session Runbook

## Before starting

1. Confirm Pi is powered.
2. Confirm camera is aimed at the G4 tray.
3. Confirm G4 ripping app is open.
4. Confirm sync path is available.
5. Clean CD if needed.

## For each disc

1. Open G4 tray.
2. Place disc label-side up.
3. Capture photos.
4. Insert disc.
5. Wait for rip and eject.
6. Remove disc.
7. Repeat.

## After session

1. Check review queue.
2. Confirm rips synced.
3. Confirm captures exist.
4. Back up archival folder.
